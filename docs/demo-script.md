# 小鲸 OrcaAI 答辩演示脚本(5分钟)

> 目标:展示五大功能全部跑通,证明"通用内核+领域包"架构的可行性。

---

## 准备(提前做好)
1. **启动服务**: `bash run.sh` (后端 8000 + 管理后台 8501)
2. **Chrome 插件已加载**: chrome://extensions/ 能看到"小鲸OrcaAI"
3. **准备演示素材**:
   - 一篇航运新闻网页(如新浪财经航运版块)
   - 一个 txt 文件(提前准备,内容随意,5-10行即可)

---

## 演示流程(按 ①-⑤ 顺序)

### 00. 开场(30秒)
**说**:"这是小鲸 OrcaAI,一个为航运知识管理优化的**通用**知识管理工具。核心特点是'通用内核+可替换领域包'——内核不含任何航运概念,航运只是当前加载的一个领域包。我用 5 分钟演示五大功能全部跑通。"

**操作**:浏览器打开 http://localhost:8501(管理后台),指着侧边栏说"五个功能模块都在这里"。

---

### ①-a. 文档收藏(插件演示,45秒)
**说**:"第一个功能是文档收藏。我在浏览器看到一篇航运新闻,点一下插件就能存入知识库,AI 自动打标签。"

**操作**:
1. 打开准备好的新闻网页
2. 点 Chrome 插件图标(或右键菜单"收藏到小鲸")
3. 插件弹窗里点"收藏" → 等待成功提示
4. 切回管理后台,刷新"文档列表"页 → **指着新增的文档**:"你看,这篇刚收藏的文章已经在了,AI 自动打了'集装箱运输'、'运价波动'等标签,这些标签来自航运领域包的 84 维标签体系。"

---

### ①-b. 搜索(30秒)
**说**:"第二,搜索。我们的混合检索融合了四个维度:向量语义、关键词、时间衰减、标签匹配。"

**操作**:
1. 侧边栏切到"智能搜索"
2. 输入框输"集装箱运价",点搜索
3. **指着搜索结果**:"你看,刚收藏的文章排在前面,因为关键词命中了。右边显示综合得分 0.25、向量 0.02、关键词 0.44——四维加权的结果。这个算法的权重可以用 NDCG 网格搜索自动寻优,可写进论文。"

---

### ①-c. 问答(30秒)
**说**:"第三,RAG 问答。用自然语言问,AI 基于知识库回答,有出处、不瞎编。"

**操作**:
1. 侧边栏切到"智能问答"
2. 输入"集装箱运价最近怎么样",点提问
3. **指着回答**:"你看,AI 基于刚才收藏的文档归纳了答案,下面列出了引用来源。如果没配 API Key,会降级为直接返回检索片段,这样离线也能演示。"

### ②. 文件上传(30秒)
**说**:"第四个功能是文件上传。支持 PDF、Word、PPT、Markdown、TXT 等格式,上传后自动解析、打标签、入库。"

**操作**:

3. **指着成功提示**:"上传成功,AI 也给它打了标签。切回文档列表能看到这个文件和刚才网页收藏的文章混在一起,统一管理。"

### ③. AI 报告生成(30秒)

**操作**:
1. 侧边栏切到"AI 报告生成"
2. 选"周度航运市场简报",点生成
3. **等待生成(10秒左右)**:"你看,AI 从知识库里抽取相关内容,按领域包定义的报告模板,生成了一份结构化的简报。这里用的提示词、检索 query 都定义在 `domains/maritime/reports.py` 里。"

## 备用应对

**Q: 为什么用 SQLite 不用 Postgres?**  
A: ADR-0002 决策,本地开发零依赖、降低门槛。生产可切 Postgres,存储层做了抽象。

**Q: 领域包怎么切换?**  
A: `.env` 里改 `ACTIVE_DOMAIN=example`,重启即可。maritime 84 标签,example 5 标签,验证过切换成功。

**Q: 离线降级是什么意思?**  
A: 没 LLM Key 时,embedding 用确定性 hash 向量、标签用关键词规则、问答返回检索片段。流程能跑通,测试可复现。见 ADR-0007。

**Q: 测试覆盖率?**  
A: 42 项测试,核心逻辑全覆盖:混合检索、中文分词、领域包加载、采集器选择、离线降级。< 1 秒跑完,不联网。
