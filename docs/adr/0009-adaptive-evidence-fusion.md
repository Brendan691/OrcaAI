# 9. 自适应证据融合与置信度感知双源校正

- 状态:已接受
- 日期:2026-08-25
- 取代:ADR-0006 中“所有查询使用固定四维权重”的部分

## 背景

ADR-0006 定义了向量、关键词、时间和标签的固定加权融合。论文第一轮实验暴露出三个问题:

- 精确法规编号查询与语义解释查询使用同一组权重,无法响应查询意图差异。
- 语料 100% 缺少可信来源发布日期,但旧实现把入库时间当作时间信号,会把“刚收藏的旧文档”误判为新内容。
- 搜索路由、RAG 问答和论文实验各自复制排序公式,算法定义会漂移。

同时,本地与 Web 证据只是直接拼接,没有依据本地检索质量分配预算,也没有跨源去重和同文档切片上限。

## 决策

引入 **自适应证据融合(Adaptive Evidence Fusion, AEF)** 深模块:

1. 查询画像:识别法规/编号/数字等精确线索、时效词、复合条件和显式标签。
2. 可靠性门控:无可信 `published_at` 时将时间权重归零;无显式标签过滤时将标签权重归零,并重新归一化。
3. 混合融合:75% 校准分数 + 25% 加权 Reciprocal Rank Fusion,降低不同信号量纲不一致的影响。
4. 证据多样性:用 MMR 风格目标惩罚高度重复文本和同文档相邻切片。
5. 双源校正:仅在用户开启联网搜索后,按本地检索置信度动态分配本地/Web预算,优先保留带定位器的本地重复来源。
6. 单一算法定义:在线搜索、RAG 和离线论文实验调用同一个生产排序模块;实验通过内部开关执行消融。

网页采集器只从结构化元数据、`article:published_time` 或 `<time datetime>` 等来源字段提取发布日期。提取不到就明确缺失,不回退到入库时间。

## 后果

- 好处:同一查询可以得到可审计的权重、可靠性和检索置信度;精确与语义查询不再被固定公式同等处理。
- 好处:缺失字段不会伪装成有效证据;时间排序的语义与论文论断一致。
- 好处:一个深模块服务搜索、问答和实验,提高 leverage 与 locality。
- 好处:冻结银标测试集上 AEF 达到 NDCG@5=0.9509,与离线网格调参上限相同,无需每次部署前重新网格搜索。
- 限制:相对默认四信号的提升在 20 条测试查询上不显著(p=0.243);缺失门控和秩融合在该语料上没有可测性能增益,只通过受控机制检查验证。
- 限制:查询画像目前是可解释规则,不是训练得到的路由器;未来需要更大、独立标注的数据集验证或学习参数。
