# 7. 无 API Key 时的离线降级

- 状态:已接受
- 日期:2026-07-27

## 背景

核心链路(向量化、问答)依赖 LLM 服务(通义千问)。但:
- 开发者申请 Key 需要时间;演示/答辩现场可能无网。
- 自动化测试不应依赖外部 API(慢、要钱、不稳定)。

若无 Key 就整条链路报错,项目"跑不起来"的观感又回来了。

## 决策

**无 API Key 时自动降级,保证流程可跑、测试可复现。**

- **Embedding**:降级为确定性 mock 向量(词袋 hash + L2 归一化)。相同文本→相同向量;共享词多→更相似。收藏、存储、检索全链路可跑通。
- **问答**:降级为直接汇总检索到的相关片段(无 LLM 归纳),并提示"配置 Key 后获得完整回答"。
- **打标签**:降级为关键词规则引擎(领域包提供关键词)。
- 是否降级由 `settings.has_api_key` 统一判定;配置真实 Key 后自动切回真实实现,业务代码无需改动。

## 后果

- 好处:零 Key 也能一键启动、完整演示流程、跑全部测试。
- 好处:测试不触外部 API,快且稳定(32+ 测试 < 1s)。
- 代价:mock 向量无真实语义,检索质量不代表真实效果——已在代码注释与界面提示中明确标注,避免误导。
- 边界:mock 仅用于开发/演示/测试。真实使用与答辩效果演示应配置 API Key。
