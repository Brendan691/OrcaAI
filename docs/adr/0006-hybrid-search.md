# 6. 混合相似度检索(核心算法)

- 状态:已接受
- 日期:2026-07-27

## 背景

纯向量检索只看"语义相似",会漏掉三类需求:精确关键词命中、新内容优先、按标签过滤。单一维度不足以支撑一个面向专业知识管理的检索。

## 决策

检索得分由四个维度**加权融合**:

```
Score = w1·向量 + w2·关键词 + w3·时间 + w4·标签    (w1+w2+w3+w4 = 1)
默认权重:0.6 / 0.2 / 0.1 / 0.1
```

- **向量**:余弦相似度经 sigmoid 增强区分度。
- **关键词**:BM25 风格 TF 打分。中文用**字符 bigram** 分词(不引入 jieba),避免整段中文被切成单一 token 而无法命中(此前的缺陷)。
- **时间**:指数衰减,半衰期 30 天。
- **标签**:查询标签与文档标签的交集比例。
- 权重可经**网格搜索 + NDCG@5** 自动寻优(`optimize_weights`),这是可写进论文的实验方法。
- 流程固定为:向量召回候选(top_k×3)→ 四维融合重排 → 取 top_k。

## 后果

- 好处:检索兼顾语义、精确、时效、分类;权重可调、可实验、可讲。
- 好处:关键词维度对中文真正生效(见测试 `test_tokenize_chinese_bigram`)。
- 代价:比纯向量多几步计算;bigram 会放大候选词数,但量级可忽略。
- 关联:mock 向量下向量维度得分偏低但非零,配置真实 API Key 后向量维度才有真实语义(见 ADR-0007)。
